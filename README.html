Platform Tata Kelola & Transparansi Anggaran Pendidikan

Sistem transparansi keuangan terintegrasi dengan database lokal mandiri 100% (Single Source of Truth PostgreSQL), mencakup 6 portal spesifik peran pengguna se-Indonesia.

💡

Anda Bukan Programmer? Tenang Saja!

Sistem ini telah dilengkapi dengan otomasi 1-klik. Anda tidak perlu memahami coding rumit atau menulis query database. Cukup pilih sistem operasi laptop/server Anda di bawah ini dan ikuti petunjuknya.

⚡ Cara Menjalankan Sistem (Pilih Sistem Operasi)

Pilih perangkat yang Anda gunakan untuk menjalankan sistem secara serentak:

🪟
Windows Localhost
Paling Mudah (1-Klik)
  • Buka folder proyek ini di Windows Explorer.
  • Klik kanan pada file start-all.ps1.
  • Pilih menu "Run with PowerShell".
  • Selesai! Seluruh 8 port akan menyala otomatis.
powershell -ExecutionPolicy Bypass -File start-all.ps1
🐧
Linux VPS (Ubuntu/Debian)
Server Production
  • Install Node.js, PostgreSQL, dan PM2.
  • Import database: node scripts/setup-db.js
  • Jalankan skrip startup: ./start.sh
  • Seluruh portal aktif di background via PM2.
chmod +x start.sh && ./start.sh
🍎
MacBook (macOS)
Terminal Homebrew
  • Buka aplikasi Terminal di Mac Anda.
  • Install dependensi: brew install node postgresql@16
  • Import database: node scripts/setup-db.js
  • Jalankan sistem: ./start.sh
node scripts/setup-db.js && ./start.sh
🐳
Docker Compose
Containerized
  • Pastikan Docker Desktop sudah terpasang.
  • Jalankan 1 perintah container di terminal.
  • Database & Proxy API akan otomatis aktif.
docker compose up -d

🐘 100% Database Lokal Mandiri — Tanpa Akun Cloud Supabase!

Sistem ini sepenuhnya mandiri (Self-Hosted) menggunakan PostgreSQL lokal (Port 2025) dan Proxy REST API (Port 2026). Anda TIDAK PERLU mendaftar atau membayar akun cloud Supabase. Untuk membuat file konfigurasi .env.local di seluruh 6 aplikasi dashboard sekaligus secara otomatis:

node scripts/setup-env.js
node scripts/setup-env.js http://IP_VPS:2026
