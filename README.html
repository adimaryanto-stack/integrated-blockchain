Sistem Tata Kelola Keuangan Pendidikan Terintegrasi

Transparansi Anggaran Pendidikan Indonesia

Platform tata kelola keuangan pendidikan nasional terintegrasi dengan basis data mandiri (*100% Single Source of Truth PostgreSQL*), menghubungkan 8 portal spesifik untuk Kementerian, Bank Penyalur, Auditor BPK, Sekolah/Institusi, Pemda APBD, Super Admin, dan Publik.

⚡ Panduan Instalasi & Eksekusi Cepat

Pilih metode instalasi sesuai sistem operasi yang Anda gunakan:

🪟
Windows Localhost
Paling Praktis (1-Klik)
  • Buka folder proyek ini di Windows Explorer.
  • Klik 2x pada file start-all.bat.
  • Database, proxy API, dan seluruh 8 dashboard akan menyala otomatis.
  • Browser akan otomatis membuka ke http://localhost:2020.
  • Untuk mematikan: Klik 2x stop-all.bat.
start-all.bat
🐧
Linux VPS (Ubuntu/Debian)
Server Production
  • Install Node.js & PostgreSQL di VPS.
  • Setup user: ALTER USER postgres WITH PASSWORD 'postgres';
  • Import database: node scripts/setup-db.js
  • Setup env: node scripts/setup-env.js http://IP_VPS:2028
  • Jalankan sistem: chmod +x start.sh && ./start.sh
node scripts/setup-db.js && ./start.sh
🍎
MacBook (macOS)
Terminal Homebrew
  • Buka aplikasi Terminal di Mac Anda.
  • Install dependensi: brew install node postgresql@16
  • Import database: node scripts/setup-db.js
  • Jalankan sistem: chmod +x start.sh && ./start.sh
node scripts/setup-db.js && ./start.sh
🐳
Docker Compose
Containerized
  • Pastikan Docker Desktop sudah aktif.
  • Nyalakan Database & Proxy: docker compose up -d
  • Jalankan dashboard aplikasi sesuai kebutuhan.
docker compose up -d

🐘 100% Database Lokal Mandiri — Tanpa Akun Cloud Supabase!

Sistem ini sepenuhnya mandiri (Self-Hosted) menggunakan PostgreSQL lokal (Port 2027) dan Proxy REST API Gateway (Port 2028). Anda TIDAK PERLU mendaftar atau membayar akun cloud Supabase. Untuk membuat file konfigurasi .env.local di seluruh aplikasi dashboard sekaligus secara otomatis:

node scripts/setup-env.js

📝 Log Update & Riwayat Pembaruan Kode

Catatan pembaruan fitur, optimasi performa, dan sinkronisasi database terkini:

🟢 Indikator Status Database Real-Time & Live Latency Ping
Menambahkan badge live indicator DB Lokal Aktif 100% [X ms] / DB Reconnecting... di seluruh header dashboard (Port 2021, 2022, 2023, 2024, 2025) dengan auto-ping berkala setiap 10 detik.
🟢 Penyelarasan Desain & Margin CSS Seluruh Halaman Publik (Port 2020)
Standarisasi kontainer max-w-7xl mx-auto px-4 md:px-8 pada seluruh halaman publik (/audit, /provinces, /statistics, /reporting, /about, /faq) agar sejajar dan konsisten 100% dengan /aliran-dana.
🟢 Trigger Otomatis PostgreSQL Cascading Delete
Implementasi trigger database trg_cascade_delete_tahun_anggaran yang secara otomatis menghapus seluruh rekaman turunan (APBD, CSR, APBN, dan alokasi wilayah) ketika suatu tahun anggaran dihapus di Kementerian.
🟢 Sinkronisasi Multi-Tahun & Rule 2027 Carry-Forward
Pembersihan 100% array data historis lama di kode frontend. Selector tahun tersinkronisasi murni dari database PostgreSQL (2026 & 2027), dengan pengeluaran Rp 0 dan saldo bank carry-forward untuk tahun perencanaan 2027.
🟢 Skrip Pembersihan Cache Otomatis (clean-cache.js)
Penyediaan skrip node scripts/clean-cache.js untuk membersihkan seluruh folder build .next dan cache build di 8 aplikasi dashboard dengan 1 perintah.
